PixelFlipper.PixelFlipping — Type
PixelFlipping([; selector, imputer, steps])

Computes pixel flipping curves.

Keyword arguments

  • selector::AbstractSelector: Specify input selector. Defaults to PixelSelector{XAIBase.NormPooling}(XAIBase.NormPooling()).
  • imputer::AbstractImputer: Specify input imputer. Defaults to ConstantImputer{Float32}(0.0f0) of value zero.
  • steps::Int: Specify number of imputation steps. Has to be smaller than the amount of selectable inputs in a sample. Defaults to 25.
  • show_progress:Bool: Show progress meter while sampling augmentations. Defaults to true.
  • device: Select array type to run pixel flipping on, e.g. CUDA.jl's cu for GPU support. Defaults to CPU Array.

PixelFlipper.PixelSelector — Type
PixelSelector()
PixelSelector(; reduce=NormPooling())

Reduces color channels in an Attribution according to reduce and returns an iterator over the indices of sorted values.

Keyword arguments

  • reduce::AbstractPooling: XAIBase pooling used to reduce color channels to a single number per "pixel" before sorting, e.g. SumPooling, NormPooling, MaxAbsPooling, SumAbsPooling or AbsSumPooling. Defaults to XAIBase.NormPooling(). This is only used for raw WHCN arrays: an Attribution reduces channels with its own pooling instead (see evaluate).

PixelFlipper.evaluate — Method
evaluate(pixelflipping, model, input, attribution::Attribution)
evaluate(pixelflipping, model, input, values::AbstractArray)
evaluate(pixelflipping, model, input, analyzer::AbstractXAIMethod)

Run the PixelFlipping method on the given model, input and attribution.

When passed an Attribution, color channels are reduced using its pooling, so that the metric evaluates the same reduction that is visualized in the heatmap. When passed a raw WHCN array, the PixelSelector's reduce is used instead.

PixelFlipper.select — Method
select(x, selector)

Return matrix of CartesianIndices of x sorted by decreasing value. Requires x to be in WHCN format, as each column in the output corresponds to an inputs in the batch.

Example

julia> selector = PixelSelector()
PixelSelector{NormPooling}(NormPooling())
